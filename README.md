Este script permite la descarga de información vectorial de las cartas topográficas de INEGI 1:50,000. 
Recuerda que la homologacíón de la información entre las cartas depende de INEGI, asi que ten cuidado con las versiones de las cartas

Si eres usuario de Qgis el Zip contiene un complemento que puedes instalar para usar en tu aplicación de escritorio.
